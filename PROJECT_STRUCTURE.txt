Tech Stack
==========
Framework:    Next.js 14 (App Router)
Language:     TypeScript
Styling:      Tailwind CSS
Animations:   Framer Motion
Icons:        Lucide React
UI Library:   React 18

Key Features
============
✅ Fully responsive (mobile, tablet, desktop)
✅ Dark mode support (auto-detects system preference)
✅ Smooth animations & transitions
✅ SEO optimized with meta tags
✅ Interactive components with hover effects
✅ Production-ready & deployment-ready
✅ Clean, maintainable code structure
✅ Type-safe with TypeScript

Sections Included
=================
1. Navigation Bar (sticky, with mobile menu)
2. Hero/Home (name, title, social links)
3. About (skills & expertise)
4. Experience (work history)
5. Projects (portfolio showcase)
6. Research (publications & awards)
7. Contact (form & contact info)
8. Footer (copyright & info)

Quick Commands
==============
Install:      npm install
Dev Server:   npm run dev
Build:        npm run build
Production:   npm start
Lint:         npm run lint

Deployment Options
==================
✓ Vercel (Recommended - 1-click deploy)
✓ Netlify
✓ GitHub Pages (static export)
✓ Your own server (Docker, PM2, etc.)
